# 水下考古潜水记录

直接打开`index.html`使用。点击沉船平面图添加标记，支持筛选、编辑、删除、时间线和导出JSON。

## 换班改动流程

- 顶栏填写**班次**（如：早班/晚班），会本地记住。
- **保存、删除不直接生效**，先进入右侧的「确认草稿」；每条标记同时只留一份未确认改动，确认后才写入地图与导出数据，放弃则不生效。
- 草稿期间同一编号被**别的班次**再改：后提交的人看到提示，新值进入「冲突项」并保留，不会覆盖前一份草稿。可「采用」冲突值替换当前草稿，或「放弃」；放弃当前草稿后，最早的冲突项自动顶上来。
- 「潜次封存」：封存前必须清空该潜次的草稿与冲突（可逐条确认/放弃，或用「清空该潜次草稿」）。封存会留存该潜次快照。
- **封存后仍可改**，但保存/删除只记入「修订履历」视图，地图、列表和导出的JSON沿用封存版。
- 把标记从一个潜次改到另一个潜次时，两个潜次的封存都会等这份草稿先了结。
- 原有类型筛选、潜次时间线、导出JSON照常使用；旧版本地数据会自动迁移。

## 文件结构

- `index.html`：页面结构与样式。
- `js/domain.js`：判断（草稿、冲突、封存、履历的业务规则），只处理数据。
- `js/store.js`：存档（localStorage 读写、旧版数据迁移、班次记忆）。
- `js/app.js`：页面操作（地图、表单、草稿箱、封存、导出的交互渲染）。
